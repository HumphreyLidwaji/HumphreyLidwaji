## AmfreOS – Security-Focused Linux OS

AmfreOS is a Debian-based operating system designed for **schools, clinics, labs, and home SOC labs**, integrating a full **Security Operations Center (SOC) stack** out of the box.  

It includes endpoint monitoring, network IDS, threat intelligence, and DFIR tools — all deployable via a simple menu system.

### 🛡️ SOC Tools Included

| Tool | Purpose | Status |
|------|---------|--------|
| ![Wazuh](https://img.shields.io/badge/Wazuh-Log%20Monitoring-blue) | Endpoint monitoring, log analysis, and auto-enrollment | |
| ![Suricata](https://img.shields.io/badge/Suricata-Network%20IDS-red) | Real-time network intrusion detection | |


### ⚙️ Features
- Automatic SOC deployment with **one command**  
- Agent auto-enrollment for endpoints  
- Clustered Wazuh servers for high availability  
- Network auto-discovery of endpoints  
- Built-in security hardening & self-healing
